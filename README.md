دليل السكر | Diabetes Guide
تطبيق لإدارة والوقاية من مرض السكري بواجهة عربية، مرتبط بخادم ذكاء اصطناعي (Python) للتنبؤ بخطر الإصابة بالسكري.

نظرة عامة
يساعد تطبيق "دليل السكر" المستخدم على تتبع وفهم وإدارة خطر الإصابة بالسكري، ويتكون من جزأين:

تطبيق الجوال (Flutter/Dart) — الواجهة التي يستخدمها المريض لتسجيل القراءات، والتعلّم عن المرض، وحجز مواعيد الأطباء.
خادم API (Python/Flask) — خدمة تعلّم آلي تتنبأ بخطر الإصابة بالسكري بناءً على المؤشرات الصحية، وتقدّم نصائح طبية مخصصة.
المزايا
تتبع السكر
تسجيل قراءات الجلوكوز على مدار اليوم — قبل وبعد الفطور، الغداء، العشاء، وقبل النوم — مع سجل مرتب بالتاريخ.

التنبؤ بخطر الإصابة بالسكري
طريقتان لتقييم الخطر:

استمارة تنبؤ تفصيلية (الجنس، عدد مرات الحمل، الجلوكوز، ضغط الدم، سمك الجلد، الأنسولين، مؤشر كتلة الجسم، التاريخ العائلي، العمر) تُرسل إلى خادم التنبؤ.
اختبار سريع من 7 أسئلة يعطي نتيجة فورية ومستوى خطر (منخفض / متوسط / مرتفع).
مكتبة الأدوية
مرجع لأنواع أدوية السكري، الأنسولين، التداخلات الدوائية، الأعراض الجانبية، وطريقة استخدام أبرة الأنسولين.

الدليل التوعوي
يشرح ما هو مرض السكري، أنواعه، أعراضه، الوقاية من النوع الثاني، وأساسيات مراقبة السكر.

التغذية
بدائل السكر، التخطيط الغذائي، الأطعمة الواجب تجنبها، ووجبات مناسبة لمرضى السكري.

الرياضة
تتبع النشاط، تمارين مناسبة، نصائح رياضية، ومقاطع فيديو تعليمية لمرضى السكري.

الأطباء والحجز
البحث عن الأطباء، عرض الملف الشخصي (التخصص، الهاتف، الموقع، ساعات العمل)، وحجز موعد بتاريخ ووقت محددين.

الفحوصات الدورية
تذكير ومعلومات حول فحص HbA1c، سكر الصائم، تحمل الجلوكوز، وفحص البول.

طريقة التشغيل
الخادم (Prediction API)
bash
cd backend
python -m venv venv
source venv/bin/activate      # على Windows: venv\Scripts\activate
pip install -r requirements.txt
python main.py
يعمل الخادم على عنوان IP المحلي للجهاز، عبر المنفذ 5000. عند التشغيل لأول مرة، إذا لم يوجد diabetes_model.pkl، يتم تدريب نموذج جديد من diabetes.csv.

المسار (Endpoint): POST /predict

جسم الطلب (Request body):

json
{
  "features": [pregnancies, glucose, blood_pressure, skin_thickness, insulin, bmi, diabetes_pedigree_function, age]
}
الاستجابة (Response):

json
{
  "prediction": 0,
  "probability": 0.23,
  "medical_advice": { "status": "...", "advice": "...", "..." : "..." },
  "features": [...],
  "processing_time_ms": 12.4,
  "timestamp": "2026-08-14T10:30:00"
}
تطبيق الجوال
bash
cd mobile_app
flutter pub get
flutter run
يجب إعداد Firebase الخاص بمشروعك أولاً (flutterfire configure) قبل التشغيل، لأن ملف firebase_options.dart مرتبط ببيئة معينة.

ملاحظات
ملفا diabetes.csv وdiabetes_model.pkl مستثنيان من التتبع في git (راجع .gitignore) لأن ملفات النموذج المدرّب والبيانات الخام لا ينبغي أن تكون ضمن المستودع. تواصل مع الفريق للحصول على البيانات/النموذج الحالي لتشغيل الخادم محلياً.
الخيار debug=True في main.py مخصص للتطوير المحلي فقط، ويجب إيقافه قبل أي نشر فعلي (production).
